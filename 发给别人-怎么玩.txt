《数与形 · 公理塔》怎么玩
========================================

一、怎么开始
----------------------------------------
双击【NumbersAndForms.exe】。

就这么一步。不用装任何东西，不用联网。

（如果 Windows 弹出蓝色的「已保护你的电脑」窗口：
  点左边的「更多信息」，再点「仍要运行」。
  这是因为这个 exe 没买数字签名证书，Windows 对陌生程序都会这么提示，
  不是病毒。）


二、界面流程
----------------------------------------
双击之后依次是：

    主菜单  →  选角色  →  载入中  →  开始爬塔

主菜单三个按钮：
    [开始游戏]    新开一局
    [继续游戏]    接着上次玩（第一次玩时是灰的）
    [退出]


三、选角色
----------------------------------------
三张卡片，各是一个角色：

    ∑  演算者     生命 80   金币 60   数字卡强化
    △  构形师     生命 92   金币 50   格挡与反伤
    χ  解方程者   生命 72   金币 75   抽牌与连击

操作：
    · 点一下卡片 = 选中（边框会变金色）
    · 再点一下同一张 = 出发

    （要连点两次是故意的，防止手滑点错就直接开局了）
    键盘也行：← → 切换，回车出发，ESC 返回


四、爬塔怎么玩
----------------------------------------
从最下面往上爬，目标是打到顶部的层主。

    [鼠标滚轮] 或 [↑] [↓]     上下看地图
    点【亮着蓝光】的节点        走过去
    点远处的节点               只看路线，不会过去
    【D】查看自己已有的牌组
    【S】存档（弹出三个存档槽选一个）
    【L】读档（弹出三个存档槽选一个）
    【M】回主菜单（进度已存档就不会丢）
    【ESC】退出游戏

地图上的符号：
    ×   普通战斗
    ◆   精英战斗（难，但给好东西）
    =   休整点（回血 或 强化一张卡）
    √   商店（花金币买卡）
    ?   事件（三选一，会影响你的状态）
    ∑   宝箱（白得一件遗物）
    ★   层主（本层最终战）

注意：连线上如果有【金色小圆圈】，说明这条路要付出代价 ——
把鼠标放上去能看到是什么代价。


五、战斗怎么打
----------------------------------------
这游戏的核心是：**想打出一张牌，得先算对一道题。**

    1. 点一张手牌（会浮起来）
    2. 再点一下空白处 = 决定用它
    3. 屏幕中间弹出一道题，等号右边是条下划线
    4. 用键盘敲数字，数字会显示在下划线上
       【退格】删一位
       【回车】提交
    5. 算对了 → 这张卡生效
       算错了 → 这张卡白费，进弃牌堆

    右下角【结束回合】= 轮到敌人行动

敌人头上会写它下一步要干什么，提前看过再决定怎么出牌。

你和敌人的血量都是头像【正下方那条血条】，数字直接写在条里：

    绿色  → 血还厚
    琥珀色 → 该小心了
    红色  → 快死了，先防一手

按【D】可以随时翻自己的牌组（见第六节）。


六、看自己有哪些牌
----------------------------------------
任何时候按【D】，都会弹出一个面板，显示你当前的全部卡牌：

    · 卡片按类型排好：数字卡（蓝框）在前，图形卡（绿框）在后
    · 左上角数字是这张卡要花几点能量
    · 顶上写着总张数和「数字 / 图形」各几张
    · 牌多的时候用【滚轮】或【↑】【↓】上下翻

按【D】或【ESC】关掉，也可以点右下角的【关闭】按钮。

战斗中也能随时按 D 看一眼（正在答题的时候除外，那时候 D 打不开）。
战斗画面【左下角】画着抽牌堆、【右下角】画着弃牌堆（小卡叠 + 数量角标），
和牌组面板里的总数对得上，方便你算还剩什么牌没抽到。


七、存档
----------------------------------------
有【三个存档槽】，可以同时保留三局不同的进度。

    按【S】-> 弹出槽位列表 -> 点一个槽（或按 1/2/3）就存进去
    按【L】-> 弹出槽位列表 -> 点一个有存档的槽接着玩
    主菜单的「继续游戏」也是进这个列表

槽位上写了那一局的关键信息（第几层、血量、金币、存档时间），
覆盖旧档时会标红提醒。打到层主会自动存一次（存进本局绑定的槽）。

存档文件在同目录的 saves 文件夹里（save_1~3.json），
想换电脑玩，把整个文件夹一起拷过去就行。
旧版只有一个 save.json 的存档会被自动认成「槽 1」，不用手动搬。

【想回主菜单】
    游戏里随时按【M】，不用退出整个程序。
    打算回去了就先按 S 存个档。


八、卡住了怎么办
----------------------------------------
【游戏窗口打不开 / 闪一下就没了】
    先确认是双击 NumbersAndForms.exe 起的。
    如果还是不行，把同目录下的 0_START_HERE.bat 双击试试，
    它会把出错信息留在屏幕上。

【画面里的中文变成方块】
    系统缺中文字体（少见，一般出现在精简版 Windows）。
    装上「微软雅黑」字体即可，或者直接找发你文件的人反馈。

【不想要存档了】
    删掉同目录下的 saves 文件夹即可，游戏会重新开始。


九、这游戏现在是什么状态
----------------------------------------
这是早期试玩版，很多内容还在做：

    · 三个角色现在只有血量和金币不一样，各自的特长技能还没做进去
    · 演算者 / 构形师已有像素立绘和动作，解方程者还是符号占位
    · 敌人还是徽章占位，卡牌、敌人、题目的种类都还比较少

玩的时候如果遇到奇怪的地方，记下来告诉发你文件的人，很有用。
