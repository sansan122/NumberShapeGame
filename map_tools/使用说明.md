# 《数与形》开发环境 · 使用说明

这份说明写给**不懂编程的人**。跟着做就行，不需要理解原理。

---

## 一、这个文件夹里有什么

```
numbers-and-forms/
├── data/
│   └── tower.yaml          ← 【你要改的就是这个】三层塔的全部配置
├── tools/
│   ├── build_map.py        ← 地图生成程序（不用动）
│   └── render_map.py       ← 网页预览程序（不用动）
├── out/
│   ├── map.json            ← 生成结果，给程序读的
│   └── map.html            ← 生成结果，双击就能看的网页
└── 一键生成地图.bat         ← 【双击这个】自动跑完并打开网页
```

---

## 二、最简单的用法

**双击 `一键生成地图.bat`** —— 就这一步。

它会自动完成：
1. 读取 `data/tower.yaml` 里的配置
2. 生成三层塔的地图
3. 在浏览器里打开预览

看到网页里出现三层塔的图，就成功了。

## 三、怎么改配置

打开 `data/tower.yaml`（用记事本就行），你会看到这样的内容：

```yaml
  - id: 1
    name: 塔基 · 数之庭
    stage: 数与运算
    rows: 12              # 本层节点行数
    width: 4              # 每行最多几个节点
```

想把这层变长一点，就把 `rows: 12` 改成 `rows: 16`，保存，再双击那个 bat 文件。

**改的时候只有两条规矩：**
1. **缩进用空格，不要用 Tab 键** —— 这是最容易踩的坑
2. **冒号后面要有一个空格** —— 要写 `name: 数之庭`，不能写 `name:数之庭`

改完存盘，重新双击 bat 即可看到效果。改坏了也不怕，原始内容在本文档最后有备份。

## 四、可以改哪些参数

### 塔层设置（`floors:` 下面）

| 参数 | 意思 | 建议范围 |
|---|---|---|
| `name` | 这层的名字 | 随便改 |
| `rows` | 这层有多少行（就是有多长） | 12–18 |
| `width` | 每行最多几个节点（就是有多宽） | 3–4 |
| `boss` | 层主名字 | 随便改 |
| `boss_hp` | 层主血量 | 见下 |
| `theme_color` | 主题色（网页上显示的颜色） | 十六进制色号 |

### 节点出现频率（`node_types:` 下面）

每个节点类型有个 `weight` 数字。**这个数字越大，这种节点出现得越多**：

| 节点 | 现在的权重 | 改大的效果 |
|---|---|---|
| 普通战斗 | 45 | 战斗更多，节奏更紧 |
| 精英战斗 | 15 | 精英更多，难度更高 |
| 休整点 | 12 | 回血机会更多，更轻松 |
| 商店 | 8 | 购物机会更多 |
| 事件 | 12 | 剧情更多 |
| 宝箱 | 8 | 白拿遗物更多 |

举例：想让游戏简单点，把 `休整点` 的 `weight` 从 12 改成 25。

### 路线代价（`path_costs:` 下面）

这是《数与形》的特色机制。四种代价的名字和效果：

| 名字 | 效果 | 数学来源 |
|---|---|---|
| 取近似 | 跳过 2 节点，失去 8 点最大生命 | 四舍五入求省事，必然丢精度 |
| 开区间 | 下一节点必为精英，但战后多 1 次强化 | 开区间端点取不到 |
| 未完待证 | 目标节点类型不可见 | 条件未证，结论未知 |
| 负债增量 | 得 1 件随机遗物，本层敌人血量 +15% | 借来的量要连本带利还 |

## 五、看到问题怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 黑窗口一闪就没了 | 配置写错了 | 用记事本打开 `tower.yaml` 检查缩进有没有用 Tab |
| 报错 `could not find expected ':'` | 冒号后少了空格 | 改成 `name: xxx`（冒号后有空格） |
| 网页打开是空白 | 还没生成地图 | 先双击 bat 文件 |
| 改了半天没变化 | 忘了存盘 | 记事本要点「文件 → 保存」 |
