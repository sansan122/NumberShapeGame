## 二、卡牌战斗怎么玩

打开后是一个 1280×720 的浅色窗口：

1. **点手牌选一张卡**（卡片会浮起变黄）
2. **再点一下空白处**＝决定打出这张卡
3. 这时会弹出一道**算术题**（比如 `7 + 5 = ?`）
4. 用**键盘输入答案**，按 `回车` 确认，按 `退格` 修改
   - ✅ **算对了**：卡牌效果生效
   - ❌ **算错了**：这张卡**直接进弃牌堆**，不生效
5. 点右下角 **「结束回合」** 轮到敌人行动

**核心设计**：想打牌，先算对。数学不是外挂的答题小游戏，而是出牌的**前置门槛**。

### 手牌类型

| 卡 | 类型 | 效果 |
|---|---|---|
| 加一 | 数字 | 造成伤害 |
| 凑十 | 数字 | 造成伤害 |
| 平方 | 数字 | 造成伤害 |
| 三角盾 | 图形 | 获得格挡 |
| 方阵 | 图形 | 获得格挡 |
| 镜像 | 图形 | 抽牌 |
| 归零 | 图形 | 清空敌人格挡 |

### 界面元素

- 左上是「演算者」（你自己）：生命 / 能量 / **形值**
- 右上是敌人「几何魔像」：生命 / **意图**（下回合要干什么，提前告诉你）
- 右中是**战报**：每次操作的文字记录
- 下方是手牌区，左下角是操作提示

## 四、地图工具

运行 `map_tools\2_gen_map.bat`，会：

1. 读取 `data/tower.yaml` 里的三层塔配置
2. 生成节点与连边 → `out/map.json`
3. 画成一张 SVG 网页 → `out/map.html`，并**自动用浏览器打开**

当前输出：

| 层 | 名称 | 节点 | 连边 | 带代价的边 |
|---|---|---|---|---|
| 1 | 塔基 · 数之庭 | 30 | 48 | 7 |
| 2 | 塔身 · 形之廊 | 33 | 49 | 6 |
| 3 | 塔冠 · 方程之顶 | 35 | 60 | 9 |

随机种子固定在 `build_map.py` 的 `SEED = 20260915`，所以每次生成结果一致。
想换一张地图，把 `SEED` 改成别的数字再跑一次即可。

## 五、避坑记录（踩过的坑，别再踩）

### 1. `.bat` 报 `Code language not supported or defined`

**现象**：双击脚本，窗口一闪，报这行错。

**原因**：`cmd.exe` 按 **GBK** 解码 `.bat` 文件，但文件是 **UTF-8** 存的。
里面的中文变成乱码，乱码行里的 `chcp 65001` 也无法识别，于是报错。

**解决**（已在本项目全部改好）：
- `.bat` 内容**只用 ASCII 字符**（纯英文提示）
- `.bat` 文件用 **GBK 编码**保存
- **不写 `chcp 65001`**

这样在任何中文 Windows 上双击都正常，且不需要管理员权限。

> 如果以后要加中文提示，正确做法是用 GBK 编码写 `.bat`，
> 而不是改成 UTF-8 再 `chcp`。

### 2. 中文文件名的 `.bat` 引用

`测试.py` 已重命名为 `my_test.py`。
纯 ASCII 的 `.bat` 引用中文文件名会因编码不一致找不到文件，统一用英文名最稳。
